# ⚛️ 원소 연금술사 (Element Alchemist)

주기율표 기반 클릭커 RPG. 수소를 모으고, 융합해서 118개 원소를 발견하고, 원소 파티로 우주의 적과 싸우세요!

## 플레이 방법
- **수집**: 원자핵을 클릭(또는 스페이스바)해 수소(H)를 모으고 생산 시설을 구매하세요.
- **융합**: 두 원소를 합치면 원자 번호의 합에 해당하는 원소가 됩니다. 재료는 각각 3개씩 소모되고 결과물은 1개입니다. (H ×3 + H ×3 → He ×1)
  철(26)보다 무거운 원소는 추가 에너지가 필요합니다.
- **전투**: 원소로 파티를 꾸려 스테이지를 돌파하세요. 계열마다 고유 특성이 있고, 적의 약점 계열은 2배 피해를 줍니다.
- **업적 / 초신성 파편**: 업적은 영구 생산 보너스, 가끔 나타나는 🌟를 클릭하면 강력한 버프!

단일 `index.html` 파일로 동작하며, 진행 상황은 브라우저에 자동 저장됩니다.
