# ⚛️ 원소 연금술사 (Element Alchemist)

주기율표 기반 클릭커 RPG. 수소를 모으고, 융합해서 118개 원소를 발견하고, 원소 파티로 우주의 적과 싸우세요!

▶ 플레이: https://element-alchemist.vercel.app

## 플레이 방법
- **수집**: 원자핵이나 빈 배경을 클릭(또는 스페이스바)해 수소(H)를 모으고(클릭 10번 = 수소 1개) 생산 시설을 구매하세요.
- **융합**: 두 원소를 합치면 원자 번호의 합에 해당하는 원소가 됩니다. 재료는 각각 30개씩 소모되고 결과물은 1개입니다. (H ×30 + H ×30 → He ×1) 결과물 칸을 누르면 해금된 원소 중 만들 원소를 골라 재료를 자동 세팅할 수 있습니다.
  철(26)보다 무거운 원소는 추가 에너지가 필요합니다.
  후반 원소는 다중 합성: 55~80번은 재료 3종(각 100개), 81번 이상은 재료 4종(각 300개).
- **조합법 해금**: 처음엔 1~10번만 융합할 수 있고, 5스테이지마다 다음 단계가 열립니다. 50스테이지에서 자연 원소(1~92번) 전부 해금.
- **인공 원소**: Tc(43), Pm(61), 93~118번은 자연에 거의 없어 융합 불가. 지정된 보스 층에 인공 원소 보스로 등장, 처치 시 1개 확정. 이미 지나온 인공 원소는 보스 층에서 4% 확률로 희귀 보스로 재등장. 등장 층은 25층(Tc) ~ 300층(Og) 고정 — 마지막 원소는 300층 보스. 환생하면 같은 층에서 다시 등장, 이미 잡은 층에선 재등장 X.
- **전투**: 원소로 파티를 꾸려 최종 스테이지 5000까지 돌파하세요. 보스는 30초 제한(타이머 게이지 표시). 계열마다 고유 특성이 있고, 적의 약점 계열은 2배 피해. 적을 클릭하면 파티 공격 쿨타임이 0.1초 줄어듭니다. ✨ 최고 덱 편성은 지금 싸우는 몬스터의 약점 계열을 반드시 포함하고, 🔄 적마다 자동 편성도 가능. 전투력은 원자 번호가 클수록 크게 오르고, 보유 개수는 자릿수만큼만 반영돼요.
- **환생(빅뱅)**: 118개 원소를 모두 모으고 빅뱅 에너지(수소 10조 × 씨앗 보너스 × 3^환생 횟수)를 모으면 별의 씨앗을 받고 새 우주에서 다시 시작. 씨앗 1개당 생산량 ×1.08, 전투력 ×1.06 (복리, 영구). 환생 후엔 역대 최고 기록의 절반까지 워프 가능.
- **스테이지 상한**: 환생 횟수에 따라 도전 가능 스테이지가 열립니다 (0회 300 · 1회 600 · 2회 1000 · 3회 1500 · 4회 2200 · 5회 3000 · 6회 4000 · 7회 5000).
- **상점**: 원소를 팔아 🪙 코인을 얻고, 코인으로 원소를 강화하면 그 원소의 공격력·체력이 레벨마다 ×1.2 (복리). 수량 버튼(×1·×10·×100·절반)은 판매와 강화 모두에 적용돼요.
- **💎 코인 투자소** (상점 탭): 수소·무기·방어 펀드(끝없이 레벨업, 레벨마다 생산/공격/체력 ×1.2, 가격 ×25) · ⏩ 시간 가속(코인 20% → 수소 생산 30분어치, 10분마다) · ✨ 황금 원자 부르기(코인 10%, 5분마다).
- **환생 강화**: 환생할 때마다 생산 탭 강화가 5개씩 새로 열려요 (환생 1~10회, 수소 생산 ×1.5 · 클릭 ×3 · 공격 ×2 · 체력 ×2 · 판매 코인 ×2). 회차마다 다시 사야 하고 가격은 빅뱅 에너지에 비례.
- **공허 (우주 창조)**: 주기율표 순서대로 원소를 바치면 새로운 우주가 태어나요. 수소 1000조 개에서 시작해 뒤로 갈수록 필요량 감소(He 18조 · Fe 550만 · U 8.6만 · 인공 원소 각 1개). 원소 하나 완료마다 생산량 ×1.02 (환생해도 유지).
- **생명의 행성**: 우주를 완성하면 공허 탭이 「🌍 행성」이 되고, 「🌱 생명의 행성으로」(신의 권능 해금 1조 코인)에서 **레벨 1~5** 행성을 순서대로 생명의 행성으로 바꿔요 (작은 불씨 → 용암 → 유황 구름 → 쌍성의 불지옥 → 종말의 행성, 레벨 5 클리어 시 엔딩 3). 전체 화면 가운데에 **도트 그림의 자전하는 행성**, 아래에 권능 단축 바(권능 24종(대기·산소·염도 조절, 토양 형성, 오존 생성, 오염 정화, 궤도 요격, 종자 보관소 포함), 숫자키 1~0). 🔍 **Ctrl+휠**(모바일은 두 손가락)로 3단계: 행성 → 도트 지상 → **🗺️ 펼친 행성**(행성 전체를 2:1 직사각형으로 편 지도, 동서로 이어짐, 생물 40종·식물 7종, 최대 약 9,000개체, 끌기 이동·휠 확대·Ctrl+휠 커서 쪽 확대, 커서/길게 누르기로 이름 표시, 마을·진화 연표·지질 시대). 지상 화면: 낮/밤, 비·폭풍(번개)·눈·화산재, 용암·바다, 자라는 나무, 돌아다니는 물고기·공룡·새·포유류·사람. 수치 10종, 레벨별 미션 13개, 시네마틱·충격파·섬광·불꽃놀이 연출, 소행성 격추·태양 플레어·초화산·유성우, 생물 도감 12종, 시간 배속, 📸 사진 저장, 행성 이름 짓기.
- **생명의 행성 난이도**: 레벨이 오를수록 권능 효과 ↓(×1.3 → ×0.5), 비용 ↑(×0.5 → ×8), 쿨타임 ↑, 목표 범위가 좁아지고 재해가 잦아져요(×0.6 → ×3.2). 대해일·대역병·초대형 폭풍·대화재·빙하기·멸종 소행성·감마선 폭발(10초 안에 보호막이 없으면 전멸), 그리고 수치의 조화가 깨지면 그에 맞는 재해 13종. 행성 시간(성장·쿨타임·보호막·재해)은 행성 화면을 보고 있을 때만 흐르고 배속도 똑같이 적용돼요. 소행성·감마선 경보 중에는 ×1. 미션 보상은 레벨당 1회. 레벨 5는 보호막 타이밍이 핵심.
- **엔딩**: 5000층 최종 보스 「빅 크런치」 처치 → 엔딩 1 · 공허에서 우주 창조 → 엔딩 2 · 생명의 행성 레벨 5 클리어 → 엔딩 3.

관리자 모드는 `/admin` 또는 `#admin` 링크로 들어왔을 때만 설정 탭에 보여요 (엔딩 1·2·3 직후로 이동, 공허 봉헌 원소·빅뱅 에너지·씨앗·코인 지급 등). 새 업데이트는 먼저 **관리자 모드에서만** 보이고, 관리자 패널의 「📢 일반 사이트에 배포」를 누르면 모두에게 공개돼요 (`/api/release`, DB `settings` 테이블).

게임은 한 탭에서만 실행되고(진행 덮어쓰기 방지), 저장 코드를 불러오기 전 상태는 자동 백업돼요.

## 계정 · 서버
- 아이디·비밀번호 계정(이메일 없음, 복구 불가)과 클라우드 저장. 로그인 없이 게스트 플레이도 가능.
- Vercel Functions(`api/`) + Neon Postgres. 비밀번호는 scrypt 해시, 세션 토큰은 해시로만 저장.
- 필요한 환경 변수: `DATABASE_URL`, `ADMIN_PASSWORD`. 값은 저장소에 넣지 않아요.
- 오프라인 보상은 서버 시각 기준. 게임 계산은 브라우저에서 하므로 저장값 조작까지 막지는 않아요.

게임 화면은 `index.html` 하나로 동작하고 (파일로 열면 게스트 전용), 진행 상황은 브라우저에 자동 저장됩니다. 홈 화면 설치(PWA)용 `manifest.webmanifest`·`sw.js`·아이콘과 링크 공유 미리보기 이미지(`og.png`)가 함께 있어요.
- **빅 크런치 소실 사건 일정**: 2부(공개 2단계)가 공개되기 전에 이미 엔딩 1을 본 계정은 공개 뒤 처음 들어온 때부터 30분~2시간 뒤, 공개 뒤에 5000층을 깬 계정은 하루 + 3~12시간 뒤 (서버 시각).
- **워프로 건너뛴 인공 원소 보스**: ⏩ 워프를 누르면 아직 못 잡은 인공 원소 보스가 워프한 층 바로 다음 보스 층부터 차례로(5층마다) 옮겨져 나와요 (워프 층이 상한이면 상한 바로 아래 층들). 그래도 지나친 보스가 있으면 원자핵 아래 안내를 눌러 그 층으로 갔다가 원래 층으로 돌아와요.
- **🌑 2부 2500층 「중력 붕괴」 (공개 8단계)**: 빅 크런치 보스전은 운 + 실력 게임. 매 턴 🎲 중력 주사위(블랙홀 ×3 · 역회전 · 가속 · 평온 · 확장 · 행운)로 조건이 정해지고, 회전하는 바늘을 초록(좋아요)·금색(완벽 ×2, 25% 치명타) 구역에서 멈춰 공격. 빗나가면 반격 ×1.5 + 흡입 +25%, 좋아요 +8%, 완벽은 반격 절반. 흡입 100% 또는 12턴 초과 시 패배 → 100~150층 뒤로(최고 기록도 그 층으로, 자동 진행 켜짐). 5000층 카드 결투 패배는 150~250층 뒤로.
- **2부 채굴 원소 표시**: 헬륨 이상을 캐는 중이면 맨 위 수소 옆에 그 원소 보유량이 나와요.
- **🃏 5000층 카드 결투 개편 (공개 9단계)**: 라운드마다 선공 미니게임이 ⚡ 연타 · 🚦 반응 속도(신호 후 빅 립보다 먼저, 부정 출발 시 패배) · 🎯 조준(움직이는 표시를 구역에, 구역 안이어도 빅 립이 운으로 이길 수 있음)으로 돌아가요. 선공 +15% · 압도적 +40%로 🌟 필살 게이지가 차고 100%면 「원소 대폭발」(×3, 보호막 무시). 빅 립은 체력 66%·33%에서 3페이즈(피해 ×1 → ×1.3 → ×1.6, 3페이즈엔 보호막을 찢는 ✂️ 시공 절단). 카드 1장 = 일반 전투 2.5초어치로 2500층보다 어려워요.
- **링크 미리보기**: og-v2.png (1200×630, 1부·2부 소개).
- **🔎 검색 · 원소 고르기 (공개 7단계 = 6.5)**: 원소 상점 · 2부 공방 · 무기 강화 · 융합 결과 고르기 · 2부 캘 원소 고르기에 검색(이름 · 기호 · 원자 번호 · 무기 이름 · 계열). 2부 원소 고르기 버튼을 크게, 패널 폭을 꽉 채우게.
- **⚔️ 2부 무기 강화 중심 (공개 10단계)**: 2부에선 이온 빔 증폭기·전자기 보호막이 레벨당 ×1.2(1부 ×1.5), 무기 강화 가격 증가 ×1.7 → ×1.4. 🪙 코인: 몹 처치 보상의 3%(보스 ×3) · 상점 「코인 투자소」 탭의 수소 환전소(수소 5% → 1개당 0.02코인, 10분마다). 시뮬레이션: 무기 강화 없이는 44층에서 멈추고, 무기 강화를 하면 4999층까지 약 209시간(막힘 최대 2.3시간).
- **우클릭 막기**: 게임 안에서는 우클릭 메뉴가 뜨지 않아요(입력 칸 제외).
- **🌑 공개 11단계**: 빅 크런치 파편(「빅 크런치의 파편」 보스 10층부터 40층마다, 40%) 100개로 2500층 소환(한 번 잡은 뒤 재전투는 50개 · 지면 절반 돌려받음) · 부족하면 「파편 모으러 가기」 · 🏛️ 전시장 보스 → 「⚔️ 이 층으로」 · ⏫ 최고 층 버튼 · 빅 크런치·빅 립 전투 중 회복 · 빅 립 결투 체력 ×1.6 · 한 방 최소 12% · 빅 립 이야기(첫 만남·처치) · 2부에서 빅 크런치를 잡으면 1부 전시장으로 돌아옴 · 💥 입자 충돌기: 47종(반입자 12 · 강입자 10 · 가상 입자 8 · 신화 등급) · ✨ 빛나는 입자 1% · 도감 보너스(종류 +3%, 빛나는 +5%) · 같은 입자 상한이 빔 출력마다 +10(최대 230) · ×100 충돌 · 효과는 같은 종류끼리 더하기.
- **📋 플레이어 기록 보강**: 「정체」(최고층이 마지막으로 오른 뒤 지난 플레이 시간, 3시간 넘으면 빨강 — 막힌 곳 찾기) · ⚠️ 저장 이상 표시(숫자 깨짐 = 오버플로 피해 의심 · 층 상한 초과 = 조작 의심 · 수치 상한 근처). 막지는 않고 관리자에게만 보여요.
- **🚦 반응 속도 보정**: 터치 화면은 반응이 늦게 잡혀서 60ms 보정.

## 🧪 자동 점검
배포 전에 엣지/크롬 헤드리스로 확인해요 (`tests/`, 사이트에는 올라가지 않음 — `.vercelignore`).
- `npm test` — 16가지 점검(최대 융합 회귀 · 오버플로 · 저장 필드 · 2부 해금 층 · 무기 재료 · 카드 뽑기 · 입자 충돌기 상한/보호 · 파편 · 2500/5000층 보스 시작 · 2부 환생 · 1부 워프 · 우클릭 · 모바일 가로 스크롤)
- `npm run test:balance` — 2부 전체 시뮬레이션(수 분): 4999층 도달 · 4시간 넘게 막히는 곳 없음 · 무기 강화 없이는 300층 전에 멈춤
- **보스 최소 싸움 길이 (11단계)**: 보스 체력 ≥ 내 기본 공격 카드 2500층 8장 · 5000층 12장분 — 강해져서 다시 와도 한두 방에 끝나지 않고, 겨우 도착한 플레이어는 그대로.
- **관리자 모드는 admin 계정 전용**: /admin으로 들어와도 admin 계정으로 로그인했을 때만 관리자 버튼이 보여요 (서버 비밀번호 확인은 그대로). 관리자 패널: 🌑 파편 +100 · 😰 빠듯한 스펙.
- **🆕 자동 업데이트**: 앱·탭이 켜져 있어도 3분마다(그리고 앱으로 돌아올 때) 공개 단계를 다시 확인해 바로 반영하고, 사이트 파일(ETag)이 바뀌었으면 저장(클라우드 포함)한 뒤 새로고침해요. 보스전·이야기·엔딩·오락실·입력 중이면 끝난 뒤에.
