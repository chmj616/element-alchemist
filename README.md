# ⚛️ 원소 연금술사 (Element Alchemist)

주기율표 기반 클릭커 RPG. 수소를 모으고, 융합해서 118개 원소를 발견하고, 원소 파티로 우주의 적과 싸우세요!

▶ 플레이: https://element-alchemist.vercel.app

## 플레이 방법
- **수집**: 원자핵을 클릭(또는 스페이스바)해 수소(H)를 모으고(클릭 10번 = 수소 1개) 생산 시설을 구매하세요.
- **융합**: 두 원소를 합치면 원자 번호의 합에 해당하는 원소가 됩니다. 재료는 각각 30개씩 소모되고 결과물은 1개입니다. (H ×30 + H ×30 → He ×1) 결과물 칸을 누르면 해금된 원소 중 만들 원소를 골라 재료를 자동 세팅할 수 있습니다.
  철(26)보다 무거운 원소는 추가 에너지가 필요합니다.
- **조합법 해금**: 처음엔 1~10번만 융합할 수 있고, 5스테이지마다 다음 단계가 열립니다. 50스테이지에서 자연 원소(1~92번) 전부 해금.
- **인공 원소**: Tc(43), Pm(61), 93~118번은 자연에 거의 없어 융합 불가. 특정 스테이지(23, 38, 52~127) 클리어 보상으로만 얻습니다.
- **전투**: 원소로 파티를 꾸려 최종 스테이지 5000까지 돌파하세요. 보스는 30초 제한(타이머 게이지 표시). 계열마다 고유 특성이 있고, 적의 약점 계열은 2배 피해. 적을 클릭하면 파티 공격 쿨타임이 0.1초 줄어듭니다. ✨ 최고 덱 편성 버튼으로 자동 편성도 가능.
- **환생(빅뱅)**: 118개 원소를 모두 모으면 별의 씨앗을 받고 새 우주에서 다시 시작. 씨앗 1개당 생산량 ×1.08, 전투력 ×1.06 (복리, 영구). 환생 후엔 역대 최고 기록의 절반까지 워프 가능.
- **스테이지 상한**: 환생 횟수에 따라 도전 가능 스테이지가 열립니다 (0회 300 · 1회 600 · 2회 1000 · 3회 1500 · 4회 2200 · 5회 3000 · 6회 4000 · 7회 5000).
- **상점**: 원소를 팔아 🪙 코인을 얻고, 코인으로 원소를 강화하면 그 원소의 공격력·체력이 레벨마다 ×1.2 (복리).
- **업적 / 초신성 파편**: 업적은 영구 생산 보너스, 3~5분마다 나타나는 🌟를 클릭하면 강력한 버프!

단일 `index.html` 파일로 동작하며, 진행 상황은 브라우저에 자동 저장됩니다.
